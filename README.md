# 🛍️ پروژه تحلیل داده‌های Online Retail

## 📌 معرفی پروژه
در این پروژه دیتاست Online Retail با استفاده از Python مورد بررسی، پاک‌سازی و تحلیل اکتشافی قرار گرفته است.  
تمرکز اصلی روی بررسی کیفیت داده‌ها، شناسایی مقادیر نامعتبر، حذف داده‌های غیرمنطقی و تحلیل الگوهای اولیه خرید مشتریان بوده است.

---

## 🛠️ ابزارها و کتابخانه‌های استفاده‌شده
- Python  
- Pandas  
- Matplotlib  
- Seaborn  

---

## 🧹 مراحل Data Cleaning
در این پروژه مراحل زیر برای پاک‌سازی داده‌ها انجام شده است:

- بررسی ابعاد دیتاست و نوع داده‌های ستون‌ها  
- بررسی مقادیر گمشده (isnull)  
- بررسی داده‌های تکراری (duplicated)  
- بررسی آمار توصیفی (describe)  
- بررسی Outlierها با Boxplot  
- حذف مقادیر نامعتبر از ستون Quantity (مقادیر منفی یا صفر)  
- حذف مقادیر نامعتبر از ستون UnitPrice (قیمت‌های غیرواقعی یا صفر)  
- ساخت دیتاست پاک‌سازی‌شده با نام df_clean

---

## 📊 تحلیل اکتشافی داده‌ها (EDA)
برای بررسی رفتار داده‌ها و الگوهای خرید، نمودارهای زیر رسم شده‌اند:

- Histogram + KDE برای بررسی توزیع Quantity  
- Histogram + KDE برای بررسی توزیع UnitPrice  
- Countplot برای بررسی تعداد تراکنش‌ها بر اساس Country  
- Scatter Plot برای بررسی رابطه Quantity و UnitPrice  
- Boxplot برای مقایسه Quantity بین کشورها  
- Boxplot برای مقایسه UnitPrice بین کشورها  
- Correlation Heatmap برای بررسی ارتباط میان متغیرهای عددی  

---

## 🔍 مهم‌ترین نتایج تحلیل
- توزیع Quantity چولگی مثبت دارد → بیشتر خریدها تعداد کم دارند.  
- توزیع UnitPrice چولگی مثبت دارد → بیشتر محصولات قیمت پایین دارند.  
- بیشترین تراکنش‌ها مربوط به United Kingdom است.  
- رابطه خطی قوی بین Quantity و UnitPrice مشاهده نشد.  
- تنوع خرید در UK بیشتر از سایر کشورهاست.  
- Correlation Heatmap نشان داد رابطهٔ خطی قابل‌توجهی بین متغیرهای عددی وجود ندارد.
